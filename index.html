PROJECT NOTES

Small, reliable, useful.

A deliberately curated research index for original AI thinking, technical essays, agent engineering, and substantive quant research. No generated summaries or AI API.

↻

How updates work

GitHub Actions runs the collector once per day. It checks RSS/Atom feeds first, then tries a sitemap or a small set of links from the source page. New entries are deduplicated by canonical URL and stored as JSON for the static site.

Some sites do not expose stable feeds or public article archives. These remain visible in the directory but may need a manually configured feed URL or archive page.

↗

Original links only

Article titles link directly to the publisher. The site does not republish full articles.

∅

No AI calls

No LLM summaries, embeddings, or classification API is used. Source approval and topic filtering are deterministic and use no model calls. The collector filters titles and publisher-provided excerpts for relevance; source-quality labels reflect editorial monitoring priority, not objective truth.

⚙

Open configuration

Edit data/sources.json to add sources, topics, feed URLs, and quant-firm tiers. The next collection run will use the updated registry.

⌁

Collection status

The collector records which sources returned content and which need attention in data/collector_status.json. A source without a feed is not automatically assumed to be inactive.

◎

Seed resource index

The initial English-first AI researcher and lab directory is based on the public AI 博客资源完整索引. Quant firms and interview sources are an additional curated directory. Check individual sources and their current URLs before relying on collection coverage.
